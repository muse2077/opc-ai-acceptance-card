# OPC AI 小项目验收卡

一套给独立创作者使用的 Markdown 模板，帮助在动手前说清 AI 小项目要做什么、怎样验收，以及哪些事情必须由人确认。

## 简单用法

1. 复制 `templates/验收卡.md`，填写目标、输入输出和验收条件。
2. 对照 `templates/示例-文章摘要助手.md`，补齐正常与异常情况的测试用例。
3. 在真实环境中自行测试；涉及隐私、安全或对外发布时由人工复核。

## 内容清单

- `templates/验收卡.md`：可复制填写的通用项目验收卡。
- `templates/示例-文章摘要助手.md`：含三个具体测试用例的示例。

## 限制

本项目只是 Markdown 模板，不是已上线应用，不连接或调用模型，不含实际测试结果，也不代表已有用户或成果。模板不能代替真实测试、专业判断或隐私审查。不要在模板、提示词或测试材料中放 API key、密码、个人资料或未经授权的原文。
